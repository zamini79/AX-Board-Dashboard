

# 대시보드 임팩트 개편안

## 현재 문제점
- AI 브리핑이 전체 가로폭을 차지하여 핵심 데이터가 아래로 밀림
- 신호등 카드 3개가 별도 섹션으로 수직 공간 낭비
- FHD에서 스크롤 없이 전체 현황 파악 불가
- 첫 화면 진입 시 "경영 현황판" 느낌보다 "리스트 나열" 느낌

## 개편 방향

### 1. Executive Summary Bar (상단 한 줄 요약)
대시보드 최상단에 한 줄짜리 요약 바를 추가합니다. CEO가 접속하자마자 핵심 숫자를 즉시 파악할 수 있습니다.

```text
+-----------------------------------------------------------------------+
| KPI: 🟢 3  🟡 1  🔴 2  |  과제: 12건 진행  |  예산 집행률: 42.3%    |
+-----------------------------------------------------------------------+
```

- KPI 신호등, 진행 중 과제 수, 예산 집행률을 **인라인 Badge** 한 줄로 표시
- 기존 신호등 3-Card 섹션 제거 (수직 공간 절약)

### 2. 전체 레이아웃 3컬럼화 (FHD 최적화)
기존 5컬럼(3:2) 구조를 **12컬럼(4:5:3)** 으로 변경하여 FHD 화면을 최대한 활용합니다.

```text
+------------------+----------------------+----------------+
|  AI 브리핑 (좌)  |   KPI 현황 (중앙)    |  To-Do/알림    |
|  + 주의 필요     |   + 주의 과제        |  + 예산 스냅샷  |
|                  |                      |  + 오늘 일정   |
+------------------+----------------------+----------------+
```

- 좌측 (col-span-3): AI 브리핑 + 주의 필요 위젯 (세로 스택)
- 중앙 (col-span-5): KPI 카드 + 주의 필요 과제 (메인 콘텐츠)
- 우측 (col-span-4): To-Do + 예산 + 일정

### 3. 과제 진행률 도넛 차트 추가
Executive Summary Bar 또는 KPI 섹션 옆에 과제 상태별 도넛 차트를 배치합니다. 미시작/진행중/완료/지연 비율을 시각적으로 표현하여 한 눈에 업무 부하를 파악할 수 있게 합니다.

### 4. AI 브리핑 카드 컴팩트화
- 높이 제한 (`max-h-[180px]`, overflow-y-auto)
- 전체 폭 사용 대신 좌측 컬럼으로 이동

### 5. 간격 최적화
- grid gap `gap-6` -> `gap-4`
- 카드 내부 padding 축소
- 섹션 간 space-y `6` -> `4`

### 최종 레이아웃 (FHD 1920x1080)

```text
+------------------------------------------------------------------------+
| [Nav Bar]                                                               |
+------------------------------------------------------------------------+
| 🟢 3  🟡 1  🔴 2  |  진행과제 12건  |  예산집행 42.3%  | Executive Bar |
+------------------------------------------------------------------------+
| AI 브리핑      | KPI 카드 (2x2 그리드)          | To-Do (내 과제/승인)  |
| (컴팩트)       |                                |                      |
|                |                                |                      |
+----------------+                                +----------------------+
| 주의 필요      | 주의 필요 과제 리스트          | 예산 스냅샷           |
| (Attention)    |                                |                      |
|                |                                +----------------------+
|                |                                | 오늘 일정            |
+----------------+--------------------------------+----------------------+
```

이 구조로 FHD 화면에서 스크롤 없이 경영 현황 전체를 한 눈에 파악할 수 있으며, 첫 화면 진입 시 "경영 상황판(Command Center)" 느낌을 줄 수 있습니다.
